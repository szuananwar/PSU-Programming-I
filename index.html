Chapter 4 — Control Structures I

Make decisions with if, else if, and switch

Selections allow programs to choose an action. A relational expression evaluates to true or false. This lesson follows the Chapter 4 sequence: comparisons, logical expressions, one-way/two-way selection, multiway selection, and switch.

1. Relational and logical operators

== equals, != not equal, < / > less/greater, <= / >= inclusive. Use && for AND, || for OR, and ! for NOT.

int score;
cin >> score;
if (score >= 70 && score <= 100) {
    cout << "Passed";
} else {
    cout << "Not passed";
}
Common mistake: if (score = 70) assigns 70 instead of comparing. Use == to test equality. A semicolon immediately after the if (...) header also changes the logic.

2. Multiway decisions

if (temperature >= 90) {
    cout << "Hot";
} else if (temperature >= 70) {
    cout << "Warm";
} else {
    cout << "Cool";
}

3. switch for menu choices

switch (choice) {
    case 1: cout << "Deposit"; break;
    case 2: cout << "Withdraw"; break;
    default: cout << "Unknown choice";
}

Use break to prevent unintended fall-through. A switch label uses case 1: (a colon, not a semicolon). For ranges such as score >= 70, an if/else if chain is usually clearer.

Chapter 5 — Control Structures II

Loops: while, for, do-while, break, and continue

The slides cover counter-controlled, sentinel-controlled, flag-controlled, and end-of-file loops; plus break, continue, and nested loops. Always identify the starting value, condition, body, and update.

1. Counter-controlled while loop

int day = 1;
int total = 0;
while (day <= 7) {
    int calories;
    cin >> calories;
    total += calories;
    day++;
}
cout << total / 7.0;

This reads seven daily values and calculates the average. day++, ++day, day += 1 and day = day + 1 all increment the counter by one in this context.

2. Sentinel-controlled loop

int value, total = 0;
cin >> value;
while (value != -1) {
    total += value;
    cin >> value;
}
cout << total;

Reading the next value inside the loop prevents an infinite loop. The sentinel -1 ends input and is not added.

3. for loop: running product

int product = 1;
for (int i = 1; i <= n; i++) {
    product *= i;
}

4. do-while: validate user input

int age;
do {
    cout << "Enter age 1–120: ";
    cin >> age;
} while (age < 1 || age > 120);
A while loop may run zero times. A do-while loop runs its body at least once and ends with while(condition);. Use a condition that can eventually become false.

5. break: exit a loop immediately

break; ends the nearest enclosing loop. The next statement executed is after the loop. It is helpful when searching for a value, rejecting an invalid input, or ending a menu. It does not exit the whole function.

int position = -1;
for (int i = 0; i < 8; i++) {
    if (numbers[i] == target) {
        position = i;
        break; // leave the loop once found
    }
}
Trace: If the first matching value is at index 3, position becomes 3. The later indices are not examined.

6. continue: skip this iteration, not the whole loop

continue; skips the remaining statements in the current iteration. In a for loop, execution proceeds to its update expression; in a while loop, it proceeds directly to the condition test.

int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // skip even values
    }
    sum += i;
}
cout << sum; // 25

7. Avoid infinite loops when using continue with while

int i = 0;
while (i < 5) {
    i++; // update BEFORE continue
    if (i == 3) {
        continue;
    }
    cout << i << " ";
}

The output is 1 2 4 5. If i++ were after the continue, the loop could become stuck at 3.

8. Compare break and continue

break;

Exit the nearest loop completely. Example: stop searching when an item is found.

continue;

Skip the rest of one iteration. Example: ignore an invalid grade but keep reading.

Chapter 6 — User-Defined Functions · Expanded

Learn C++ functions one step at a time

Work through this chapter in order. Each step explains one idea, shows a complete example, and connects to a related practice problem. The lesson builds on the Chapter 6 slides: function calls, prototypes, formal and actual parameters, value-returning and void functions, scope, reference parameters, default arguments, and function overloading.

Before you begin: We use #include <iostream> and using namespace std;. A function definition has a body in braces. A function prototype ends in a semicolon. A function call uses the function name and arguments.

Step 1 · Why use a function?

Suppose you need to calculate sales tax for 20 purchases. Instead of rewriting the formula 20 times, write it once as a function and call it whenever needed.

double salesTax(double price) {
    return price * 0.08;
}

// Elsewhere in your program:
cout << salesTax(50);  // 4

A function is a reusable, named block of code. It can receive data, perform work, and optionally return a result.

Step 2 · Learn the five parts of a function

double rectangleArea(double width, double height) {
    double area = width * height;
    return area;
}
  1. Return type: double indicates the result type.
  2. Function name: rectangleArea.
  3. Formal parameters: double width, double height.
  4. Body: statements inside { }.
  5. Return statement: sends the result to the caller.

Step 3 · Prototype → call → definition

When the function is defined after main(), declare its prototype first so the compiler knows its name, return type, and parameter types.

#include <iostream>
using namespace std;

int square(int n);         // 1. prototype

int main() {
    int result = square(6); // 2. call
    cout << result;       // prints 36
    return 0;
}

int square(int n) {        // 3. definition
    return n * n;
}
Do not confuse: int square(int n); is a prototype. square(6) is a call. int square(int n) { return n*n; } is a definition.

Step 4 · Formal parameters vs. actual arguments

int add(int a, int b) {  // a and b: formal parameters
    return a + b;
}
int total = add(7, 9);  // 7 and 9: actual arguments

When add(7, 9) is called, its parameters receive 7 and 9. The function returns 16, which is stored in total. Parameter order matters.

Step 5 · Value-returning vs. void

double discount(double price) {
    return price * 0.10;
}

void printReceipt(double total) {
    cout << "Total: " << total << endl;
}

Use a return type such as int, double, or bool if the caller needs a value. Use void if the function performs an action but does not produce a value to be assigned.

Step 6 · Pass by value and pass by reference

void addTenByValue(int points) {
    points += 10; // changes only local copy
}
void addTenByReference(int& points) {
    points += 10; // changes original
}

int score = 50;
addTenByValue(score);      // score is still 50
addTenByReference(score);  // score is now 60

With pass-by-value, changes remain inside the function. Adding & to the formal parameter makes it a reference to the caller's variable.

Step 7 · Local scope, global variables, and static variables

int visits = 0; // global variable

void registerVisit() {
    int dailyCount = 1;   // local: new every call
    static int total = 0; // persists across calls
    total++;
    visits++;
    cout << total << endl;
}

dailyCount exists only inside the function; total keeps its value across calls. Prefer passing parameters and returning values instead of relying on mutable global variables.

Step 8 · Default parameters

double shipping(double weight, double rate = 2.0) {
    return weight * rate;
}

shipping(5);       // uses default rate: 10
shipping(5, 3.0);  // overrides rate: 15

Defaulted parameters are ordinarily placed after required parameters. When using a separate prototype, put the default in the declaration, not in both declaration and definition.

Step 9 · Function overloading

int larger(int a, int b) {
    return a > b ? a : b;
}
double larger(double a, double b) {
    return a > b ? a : b;
}

Functions can share a name if their parameter lists differ. Changing only the return type is not enough to overload a function.

Step 10 · Functions with selection and loops

int countEven(int limit) {
    int count = 0;
    for (int i = 1; i <= limit; i++) {
        if (i % 2 == 0) {
            count++;
        }
    }
    return count;
}

Trace this example: countEven(7) returns 3, because 2, 4 and 6 are even. This is how functions help organize larger problems.

Common errors to check: missing return type, prototype without ;, function header with extra ;, returning a value from void, forgetting & for a reference, mismatched parameter types, using a local variable outside its scope, or forgetting to call the function.

Suggested learning path

  1. Write a prototype, then a simple returning function.
  2. Call your function from main() and explain the output.
  3. Write a void function.
  4. Compare pass-by-value with pass-by-reference.
